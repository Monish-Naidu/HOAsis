### How to delete it

1. The product's own path: sign in as Priya, Settings, Leaving and
   closing, Delete the association, type the name. That calls
   `request_association_deletion`, which sets `deleted_at` and cancels the
   subscription; the rows stay for 30 days.
2. Hard removal, which is what the script does:
   `node scripts/seed-ten-years.mjs --remove`. It finds the association by
   `settings.qa = "ten-year"`, demotes the President (the trigger refuses
   to delete one), empties its storage folder, deletes the association row
   (everything else cascades), then deletes every auth user carrying
   `user_metadata.qa = "ten-year"`. Nothing else in the project is touched.

It is left in place for Monish to click through.
